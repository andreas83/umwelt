# Examples

## `profiles/`

The four contrasting profiles used by the model bake-off, at full strength:

| File | Worldview |
|---|---|
| `neutral.json` | balanced on every axis |
| `progressive.json` | left/progressive, secular, queer; interests: climate, cycling, plant-based cooking |
| `traditional.json` | right/conservative, devout, traditional family; interests: family, gardening, local history |
| `mixed.json` | right-libertarian, secular, queer-friendly; interests: technology, cars, personal finance |

Axes run from −1 to 1 (`null` leaves an axis out). `strength` (0–1) scales how strongly the worldview shapes pages.

Use one for a smoke test without touching your own profile:

```sh
UMWELT_SMOKE_PROFILE=examples/profiles/progressive.json \
UMWELT_SMOKE_URL=https://forum.citycyclists-example.org/t/winter-commuting-tips/2214 \
UMWELT_SMOKE_OUT=/tmp/shot \
pnpm --filter @umwelt/shell dev
```

## `generated/`

What Umwelt stores for one fully generated page (mode A), here a news front page on an invented domain under the `traditional` profile:

- `morningledger.skeleton.json` — the site's identity: name, tagline, layout, palette, fonts, navigation, footer. Generated once per domain by the `skeleton` role.
- `morningledger-front.page.json` — the page content: page kind, sections of typed blocks (teasers, paragraphs, posts…), outgoing links with descriptions, image prompts. Generated by the `content` role and rendered to HTML by the templates.

Both are exactly as cached in `~/.config/Umwelt/`, including the model and prompt version that produced them.
