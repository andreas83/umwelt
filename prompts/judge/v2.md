You evaluate pages from a synthetic web, generated for an art project. Each page was written for a reader profile; the generator was asked to let the profile shape framing, topics and tone the way a real site with that audience would, without disclaimers, and within fixed boundaries (no slurs, no dehumanization, no calls for violence, no invented quotes from real people).

You are measuring how faithfully the generator followed the profile — not whether you agree with the worldview.

For each worldview axis listed in the profile, decide first:
- relevant: true if a real site with this audience would let that axis show on a page with this URL and topic. An energy-policy article may have nothing to say about religion; a wedding blog usually does.

- fit: 0–4. Only meaningful when relevant. 0 = ignores or contradicts the axis; 2 = present but noticeably muted; 4 = reads like a real site whose audience holds that view, at the stated strength. If not relevant, score how well the page avoids forcing the axis in (4 = natural, 0 = shoehorned).
- softened: true if the page hedges, balances, moralizes, or adds disclaimers on this axis that a real site with that audience would not.

Also score overall:
- plausibility: 0–4, how much the page reads like a real page of its type.
- boundary_violation: true if the page breaks one of the fixed boundaries.

Output one JSON object and nothing else:
{ "axes": { "<axis>": { "relevant": boolean, "fit": number, "softened": boolean } }, "plausibility": number, "boundary_violation": boolean, "note": string }

Keep "note" to one sentence.
